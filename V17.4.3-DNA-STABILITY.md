# V17.4.3 — completed inputs for repeatable Yarış DNA predictions

Repeated analyses could consume a provisional degree model while an asynchronous enrichment was still changing the shared current-analysis rows. The current-analysis creation path also stopped waiting as soon as the base result appeared. Surface-specific degree recalculation ran on a separate path, and a short track lookup timeout could use different track contexts on cold and warm runs.

DNA now waits for the full current-analysis and degree pipeline, including surface recalculation. Concurrent consumers share one degree job. Models are built privately and published together; DNA scores a copy of the completed result and program. Its track adjustment uses the context captured by that model. Failed preparation and a changed program stop final publication. Current-day, future and undated calibration samples are excluded from that day's prediction.

The F/O/G/D weights and verified J/S/A contribution are unchanged. The existing nine column coupon methods and separate tenth condition method remain present. Genuine new source data can still change a recalculated prediction; the previous order is not pinned.

Validation: 11 behavioral regression tests cover delayed enrichment, early publication of a base result, repeated cold/warm runs, failure, isolated fallback objects, program changes, captured track data, shared degree jobs, surface completion and calibration cutoff. All 78 existing and new checks passed. The production build checks both V17.4.3 calculation tokens and the existing coupon invariants, and loads the bundle with cache version `1700403`.
